# Penn State Housing: On-Campus vs. Off-Campus

An interactive, static web application comparing Penn State on-campus housing areas and 50 private off-campus properties with lodging, food, commute, and full-year cost estimates.

## Features

- Search and filter 58 housing options: 8 Penn State on-campus housing areas and 50 private off-campus properties
- Clustered interactive OpenStreetMap with green campus pins, blue private-property pins, and neutral charcoal clusters
- Housing tiles use the same green on-campus and blue off-campus category palette as the map
- On-campus tiles with official 2026–27 lodging rates, meal-plan requirements, and Penn State housing links
- Google Maps and leasing-site links in every map popup
- Latest advertised rent with per-bed versus per-unit labeling
- Google Maps preview and direct map links
- Interactive full-lease off-campus cost calculator
- Selectable official 2026–27 returning-student housing and Campus Meal Plan rates
- Nittany and White Course apartment scenarios with an optional self-catered food estimate
- Grocery and one-time furniture estimates
- Year-2 dorm versus apartment advantages and trade-offs
- Apple-inspired interface with system typography, restrained translucent materials, and immediate press feedback
- Property-listing dashboard with a persistent filter sidebar and visual neighborhood cards
- Responsive layout, keyboard focus states, reduced-motion support, reduced-transparency support, and increased-contrast support

## Data limitations

Most State College landlords had not published binding 2027–28 rates when this analysis was prepared in October 2026. The application displays the latest advertised figures available at that time. Availability, rent, utilities, fees, furnishing and lease dates must be confirmed directly with each property before signing.

This is an independent planning tool and is not affiliated with Penn State University.
